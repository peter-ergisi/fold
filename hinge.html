What this browser supports

Turn it on in Safari (iPhone Duo, iOS 27.1+)

  1. Settings → Apps → Safari → Advanced → Feature Flags
  2. Turn on Device Posture API and Viewport Segments API
  3. Reload this page over https://
  4. Open the phone and hold it half-folded like a book
On Android foldables (Galaxy Z Fold, Pixel Fold), Chrome 138+ already has both APIs on by default.
